## Top 30 Critical Craft Intersections Deep Dive

### `bolder.md` — Amplifying Bland UI into Brutalism
> Apple HIG designs risk looking generic or washed-out on modern web. `bolder` injects BoldKit’s 3px borders, hard 4px drop shadows, and uppercase tracking while preserving Apple’s 44pt touch targets.

### `quieter.md` — Calming Aggressive Brutalism into Apple Composure
> Loud brutalism (clash colors, multiple thick borders, heavy shadows) can overwhelm dense productivity apps. `quieter` tones down saturation, softens borders to 2px, and restores Apple-like calm.

### `craft-floor.md` — The Universal Quality Floor
> Enforces strict non-negotiables: no unstyled text, no missing focus rings, no broken responsive overflow, and no generic purple gradients across all 3 ecosystems.

### `critique.md` — Heuristic 6-Axis Design Evaluation
> Evaluates any screen against Hierarchy, Alignment, Typography, Color, Affordance, and Delight, bridging Apple’s 8 principles with Brutalist tactile rules.

### `audit.md` — Technical Quality & Contrast Audit
> Audits source code for WCAG AA/AAA compliance, touch target sizes (44pt on iOS), and responsive breakpoints.

### `audit.native.md` — Native Platform Code Audit
> Enforces Apple HIG non-negotiables: official Apple Pay marks (never hand-drawn), safe-area insets, and edge-swipe gesture preservation.

### `mode-persuade.md` — Persuade Mode (Marketing & Action)
> Pairs BoldKit’s 14 marketing blocks (Hero, Bento, Pricing, FAQ) with Impeccable’s high-craft visual rules where design is the product.

### `mode-operate.md` — Operate Mode (Productivity & Task)
> Pairs BoldKit’s dashboard layout and TanStack tables with Apple macOS/iPadOS density conventions, muting decorative flair in favor of scanability.

### `mode-read.md` — Read Mode (Documentation & Long-form)
> Integrates Apple Dynamic Type principles and Neobrutalism code syntax styling for optimal reading comfort.

### `animate.md` — Motion Physics Synthesis
> Reconciles Apple’s organic fluid spring curves with BoldKit’s mechanical stepped easing (`motion.css`), choosing springs for modals and stamps for button clicks.

### `colorize.md` — Chromatic Strategy Synthesis
> Harmonizes Apple’s subtle semantic tints, Neobrutalism’s editorial pastels, and BoldKit’s high-voltage Neon & Clash palettes into balanced color themes.

### `typeset.md` — Typographic Hierarchy & Tabular Data
> Combines Apple’s San Francisco optical legibility with Brutalism’s high-impact uppercase tracking and monospace data numerals.

### `layout.md` — Bounding Boxes vs Spatial Rhythm
> Reconciles Apple’s 8pt grid with Brutalism’s exposed container dividing lines and offset card layers.

### `onboard.md` — First-Run Setup & Empty States
> Bridges Apple’s lightweight launch guidelines with BoldKit’s 6-step `onboarding-flow.tsx` and interactive `<Tour>` spotlight guide.

### `harden.md` — Edge Case Bulletproofing
> Protects components against extreme string lengths, missing image fallbacks, network errors, and unexpected user input.

### `distill.md` — Radical Subtraction & Clarity
> Strips unnecessary borders, extraneous canvas shaders, and decorative noise to reveal core functional utility.

### `delight.md` — Micro-Interactions & Tactile Touches
> Injects memorable character via BoldKit stickers, tape stamps, ASCII 3D shapes, and tactile press recoil physics.

### `overdrive.md` — Experimental Avant-Garde Visuals
> Activates BoldKit’s 23 WebGL canvas shaders (Plasma, Dither, MatrixRain) for high-energy creative campaigns.

### `clarify.md` — UX Microcopy & Tone of Voice
> Bridges Apple’s warm conversational voice with Brutalism’s blunt, unvarnished, action-oriented labels.

### `adapt.md` — Responsive Fluidity
> Ensures seamless layout transformation between mobile single-column touch views and desktop multi-pane dashboard shells.

### `adapt.native.md` — Foldable & Dual-Display Adaptation
> Handles Apple iPhone Duo posture changes, dynamic hinge seams, and tablet multitasking layouts.

### `optimize.md` — Performance & Frame Rate Defense
> Profiles DOM bloat, canvas shader GPU utilization, and guarantees 60fps animations while honoring `prefers-reduced-motion`.

### `live.md` — Live Browser Variant Exploration
> Picks live rendered elements in the browser and rapidly previews alternative design treatments.

### `generate.md` — Automated Design Variant Generation
> Generates 3 to 5 contrasting visual variants of a named component for client presentation.

### `component-review.md` — Single Component Craft Audit
> Examines an individual button, card, or modal against all 4 systems’ standards for borders, shadows, and accessible states.

### `region-map.md` — Macro Viewport Region Architecture
> Decomposes complex views into Header, Hero, Navigation Rail, Canvas, and Inspector zones with explicit boundary rules.

### `doctor.md` — Design System Drift Detection
> Scans project code to detect when component implementations diverge from DESIGN.md token rules.

### `hooks.md` — Automated Real-Time Linter Hooks
> Configures automated git and editor hooks that audit UI files immediately upon save.

### `init.md` — Product Truth Formalization
> Captures durable brand commitments, target personas, and aesthetic constraints in PRODUCT.md.

### `document.md` — Design Token Extraction & Reverse Engineering
> Reverse-engineers live CSS and Tailwind classes into a structured, maintainable DESIGN.md token specification.
